# English Version

## 📌 Overview

**Letterally** is a weekly prompt-based creative writing platform designed to **stimulate reflection** through weekly topics.  

Users can:
- Submit their own **essays** or **stories** based on weekly topics.
- Read other users' submissions only after contributing their own.
- Vote for their favorite essays.
- Engage with a creative writing community.

**Admins** can:
- Create and manage weekly topics
- **Moderate users' essays and comments** to ensure quality and safety.

---

## ✨ Features

- **User Authentication** (JWT-based)
- **Role Management** (Admin / User)
- **Weekly Topics** with automatic **end dates**
- **Essays** submission & browsing
- **Voting System** for essays
- **Admin Moderation**
- **Pagination & Sorting** on endpoints
- **Swagger API Docs** for easy testing

---

## 🛠 Tech Stack

- **Backend:** Java 21, Spring Boot 3.5.4, Spring Security, JWT, Lombok, Validation API
- **Frontend:** React, TypeScript, Bootstrap
- **Database:** PostgreSQL
- **API Docs:** Swagger
- **Image Management:** Cloudinary SDK
- **Build Tool:** Maven

# Versione Italiana

## 📌 Descrizione

**Letterally** è una piattaforma di **scrittura creativa** basata su prompt settimanali, pensata per **stimolare la riflessione** attraverso temi su topic importanti.

Gli utenti possono:
- Inviare **temi** e **racconti** sui topic proposti.
- Leggere gli elaborati degli altri **solo dopo aver contribuito**.
- Votare i migliori testi.
- Condividere la passione per la scrittura.

Gli **admin** possono:
- Gestire i **topic settimanali**
- **Moderare gli essay e i commenti degli utenti**.

---

## ✨ Funzionalità

- **Autenticazione Utente** (JWT)
- **Gestione Ruoli** (Admin / User)
- **Gestione Topic Settimanali** con calcolo automatico delle "end date"
- **Invio e Browsing Temi**
- **Sistema di Voti**
- **Moderazione da parte degli Admin**
- **Paginazione & Ordinamento**
- **Documentazione API Swagger**

---

## 🛠 Stack Tecnologico

- **Backend:** Java 21, Spring Boot 3.5.4, Spring Security, JWT, Lombok, Validation API
- **Frontend:** React, TypeScript, Bootstrap
- **Database:** PostgreSQL
- **API Docs:** Swagger
- **Gestione Immagini:** Cloudinary SDK
- **Build Tool:** Maven
